# ❄️ 雪夜 · 交互雪景

一个基于 p5.js 的生成艺术交互动画，模拟静谧雪夜中的飘雪、积雪、滚雪球、堆雪人与铲雪车清场。支持鼠标与触屏全平台交互。

## 🎮 在线体验

👉 [点击这里直接玩](https://senlin06110611-cpu.github.io/snow/)

## ✨ 功能特性

- 动态飘雪：200 片六角冰晶雪花，大小/速度/透明度随纵深变化
- 真实积雪：雪花落地按面积守恒堆积，自动沉降流动形成自然雪丘
- 悬停冻结：鼠标/手指靠近雪花时暂停飘落，移开继续
- 长按消融：按住鼠标/手指贴近雪花使其融化消失
- 滚雪球：在雪面上拖拽生成雪球，越滚越大（无上限），消耗脚下积雪
- 堆雪人：小雪球放到大雪球上自动组合成雪人（带眼睛和胡萝卜鼻子）
- 双击碎裂：双击雪球/雪人将其击碎成 10-15 块不规则雪块，自然下坠
- 铲雪车：拖拽橙色铲雪车擦除积雪，松手自动归位；双击铲雪车触发全场清场动画
- 路灯开关：点击路灯切换昏黄灯光，带锥形光束和地面光斑
- 远景建筑：两栋带随机亮窗的商业高楼，营造城市雪夜氛围
- 全平台适配：桌面鼠标 + 手机/平板触屏，自适应屏幕尺寸

## 🕹️ 操作指南

| 操作 | 效果 |
|------|------|
| 鼠标悬停 / 手指靠近 | 雪花暂停飘落 |
| 鼠标长按 / 手指长按 | 贴近雪花使其消融 |
| 左键拖拽雪面 / 手指拖拽雪面 | 生成并滚动雪球 |
| 左键单击雪面 / 手指点击雪面 | 留下冷蓝色脚印（2 秒后消散） |
| 双击雪球 / 双击雪人 | 击碎成不规则雪块 |
| 拖拽铲雪车 | 擦除路径上的积雪 |
| 双击铲雪车 | 全场清场动画 |
| 点击路灯 | 开关昏黄灯光 |
| ↑ / ↓ 键 | 调节飘雪速度 |
| 右上角按钮 | 调节雪花大小 / 飘雪速度 |

## 🛠️ 技术栈

- p5.js 1.9.4（实例模式）
- 纯前端静态页面，无需后端
- Canvas 2D 渲染，60fps 流畅运行

## ⚙️ 自定义参数

所有可调参数集中在 sketch.js 顶部的 CONFIG 对象中，修改后保存刷新即可生效。
